# Security policy

Never report a vulnerability in a public issue, pull request, or discussion.

The CRM holds personal and medical data about minors. A public report can expose that data before a fix exists.

## Report a vulnerability

1. Open the affected repo on GitHub.
2. Select the **Security** tab.
3. Select **Report a vulnerability**.

Only the repo's maintainers can see the report.

## What to include

- The affected repo, and the file, URL, or component.
- What an attacker can do, and what data they can see or change.
- The steps to reproduce the problem.
- The commit or version that you tested.

Do not include real personal data in the report. If you found real data, describe it, and do not copy it.

## What happens next

A maintainer responds in the report. The maintainers are volunteers, so we make no promise about response time. We work on the fix in private, with you in the report.
