# CYC Community Sailing Center

CYC Community Sailing Center is a nonprofit in Seattle. Its volunteers build these tools to run its sailing programs.

| Repo                                                            | Holds                                                                                        |
| --------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| [`platform`](https://github.com/cyc-seattle/platform)           | The shared Google Cloud platform, the Directus CRM, and the Clubspot and Google Groups syncs |
| [`isthmia`](https://github.com/cyc-seattle/isthmia)             | The Authentik sign-in and the staff portal                                                   |
| [`clubspot-sdk`](https://github.com/cyc-seattle/clubspot-sdk)   | A TypeScript client for Clubspot, and a fake of it for tests                                 |
| [`gsuite-sdk`](https://github.com/cyc-seattle/gsuite-sdk)       | Typed wrappers around the Google Workspace APIs                                              |
| [`calendar-sync`](https://github.com/cyc-seattle/calendar-sync) | A one-way sync from a Google Sheets spreadsheet to Google Calendar                           |
| [`commodore`](https://github.com/cyc-seattle/commodore)         | Shared command-line and logging helpers                                                      |
| [`gam`](https://github.com/cyc-seattle/gam)                     | Break-glass GAM scripts and templates for CYC's Google Workspace                             |
| [`.github`](https://github.com/cyc-seattle/.github)             | The default community files, reusable workflows, and Renovate preset                         |
| [`ts-config`](https://github.com/cyc-seattle/ts-config)         | Shared ESLint, Prettier, TypeScript, Vitest, and lefthook config                             |
| [`agent-skills`](https://github.com/cyc-seattle/agent-skills)   | Agent skills and sub-agents shared by the repos                                              |

## How to help

Read the [contributing guide](https://github.com/cyc-seattle/.github/blob/main/CONTRIBUTING.md). Then pick an open issue in a repo, or open a new one.
